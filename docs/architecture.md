# MedPrint 系统架构与技术规范全景

## 1. 核心设计哲学

MedPrint 摒弃传统基于 DOM 抓取的屏幕位图化方案（如 `html2canvas`），构建了一个以**绝对物理度量衡（微米/毫米）为基准**的排版与渲染体系。

## 2. 坐标与几何基准

1. **绝对精度单位**：
   - 内部统一以 `PhysicalUnit::Micrometers(u32)` 存储；
   - 毫米换算：\(1\text{ mm} = 1000\mu\text{m}\)；
   - 点（Point）换算：\(1\text{ pt} = \frac{25400}{72}\mu\text{m} \approx 352.778\mu\text{m}\)；
   - 杜绝任意 CSS 屏幕像素在排版层面的参与。

2. **纸张定义**：
   - `A5_Landscape`: \(210\text{mm} \times 148\text{mm}\)（\(210000\mu\text{m} \times 148000\mu\text{m}\)）
   - `A4_Portrait`: \(210\text{mm} \times 297\text{mm}\)
   - `A4_Landscape`: \(297\text{mm} \times 210\text{mm}\)
   - `ContinuousFeed`: 支持用户指定穿孔折叠纸宽度与单页切纸高度。

## 3. 硬件双向状态与事件状态机

`medprint-agent` 与操作系统假脱机服务交互，向宿主广播的标准生命周期事件如下：

| 事件枚举 | 触发时机 | 业务系统行为 |
| :--- | :--- | :--- |
| `JOB_SUBMITTED` | 任务成功压入本地打印假脱机队列 | 记录打印审计日志 |
| `PRINTING_PAGE` | 某物理页面正在被光栅化并向硬件传输 | 前端进度条推进 |
| `HARDWARE_PAPER_OUT` | 打印机传感器检测到纸盒缺纸 | 弹窗阻断并声音警报 |
| `HARDWARE_JAM` | 纸路卡纸或机械故障 | 弹窗告警，保留重印上下文 |
| `JOB_COMPLETED` | 最后一页物理纸张完全脱离出纸口 | **正式核销门诊处方号/医保发票号** |
| `JOB_CANCELLED` | 物理任务被人工或异常中止 | 释放凭证流水号锁 |
