# 禁止做成传统低代码

## 禁止新增

- 开放物料市场 / 任意 widget 目录（按钮、输入框、TAB、图表库、自定义 Vue 组件协议）
- **以自由 `x/y` 为模板源真相**的葡萄城式画布（导出坐标即打印几何）
- 通用表达式语言、事件绑定、`onClick`、工作流、页面路由、表单校验器
- 用户自定义组件上传、低代码 DSL、JSON Schema 动态表单生成器
- `html2canvas`、DOM 截图、屏幕像素排版
- 在未改 Rust `ReportElement` 的情况下给 ProCanvas 加新工具箱按钮

## 允许（产品约束下的灵活）

- 有限临床预设与模块开关
- **拖动封闭槽位**改变文档流顺序（松手后引擎重算毫米框）
- 槽位参数覆写：页边距、行高、折流列比、页眉对齐/院徽/报告单号、患者字段目录增删改排序、PACS 宫格、TEG 参数、印章与签名文案
- AI tool calling 生成或 patch 封闭 AST
- 画布投影引擎框，供信息科核对

## 反例 → 正例

| 错误（开放低代码） | 正确（封闭组件 + 产品灵活） |
| :--- | :--- |
| 「工具箱加任意文本控件 + 表达式」 | `NotesFooter` 或患者条「自定义」字段 |
| 「标题写死居中不能改」 | `HospitalHeader.align` + 院徽 + 报告单号 |
| 「患者条六个字段写死」 | `PatientBanner.fields` 目录增删排序 |
| 「拖到哪打印就在哪」 | 拖改 `elements` 顺序 → 引擎重排 |
| 「AI 直接改 Vue」 | AI 只返回 `ReportTemplate` AST |
